# AI 绘本生成器 - 用户故事

## 用户故事 1：聊天式绘本创作

**作为** 一个家长/教育工作者
**我想要** 通过自然对话的方式创作绘本
**以便于** 更直观地表达我的创意，而不需要填写复杂的表单

### 验收标准：
- [ ] 用户可以像聊天一样输入绘本想法
- [ ] 系统自然对话，引导用户提供更多信息
- [ ] 支持中文自然语言输入
- [ ] 生成过程可视化，用户能看到实时进度

---

## 用户故事 2：实时预览和迭代

**作为** 一个内容创作者
**我想要** 在输入的同时看到绘本的实时预览
**以便于** 及时调整和优化故事内容

### 验收标准：
- [ ] 左右分屏布局：左侧聊天，右侧预览
- [ ] 实时显示生成进度（"正在生成第1页..."）
- [ ] 逐页显示生成的内容
- [ ] 支持继续对话修改内容

---

## 用户故事 3：Figma AI 风格的交互体验

**作为** 一个设计师
**我想要** 类似 Figma AI 的流畅交互体验
**以便于** 专注于创作而不是操作界面

### 验收标准：
- [ ] 简洁的聊天界面，无需复杂配置
- [ ] AI 主动询问必要信息（年龄、画风等）
- [ ] 流畅的动画和过渡效果
- [ ] 响应式设计，适配各种屏幕

---

## 用户故事 4：渐进式信息收集

**作为** 一个用户
**我想要** 通过对话逐步完善绘本细节
**而不是** 一次性填写所有信息

### 验收标准：
- [ ] 支持一句话简单输入（如："小猩猩找妈妈的故事"）
- [ ] AI 智能追问（如："适合哪个年龄段？"）
- [ ] 可以随时调整已设定的参数
- [ ] 保留对话历史，方便查看和修改

---

## 功能流程示例

### 场景 1：首页创作
1. 用户访问首页，看到类似豆包/DeepSeek的聊天界面
2. 点击灵感示例或直接输入故事想法
3. 点击"开始创作"按钮

### 场景 2：自动进入创作界面
1. 页面自动切换到 2:8 分屏布局
2. 左侧聊天区显示用户输入和AI响应
3. 右侧预览区实时显示生成进度

### 场景 3：简单创作对话
```
用户：一个小猩猩醒来，在森林里找妈妈要抱抱的故事
AI：收到你的想法，让我为你创作一个精彩的绘本故事...
[右侧预览区开始实时显示]
```

### 场景 4：实时预览
```
[左侧聊天区]
AI：正在创作"小猩猩找抱抱"绘本...

[右侧预览区]
正在生成故事标题...
✓ 《小猩猩找抱抱》
正在生成第1页...
✓ 小猩猩宝宝睁开眼睛，发现妈妈不在身边...
正在生成插画描述...
✓ 插画描述：晨光中的森林，小猩猩揉着眼睛...
```

## 技术实现要点

1. **流式响应**：使用 Server-Sent Events (SSE) 实现实时推送
2. **对话管理**：维护对话上下文，支持多轮对话
3. **智能提示**：根据用户输入自动推断和询问必要信息
4. **渐进式展示**：分步骤展示生成过程，提升体验

---

## 设计原则

1. **对话优先**：让对话成为主要的交互方式
2. **即时反馈**：每个操作都有视觉反馈
3. **渐进式披露**：不一次性展示所有选项
4. **容错性强**：支持模糊输入和自然修正

---

## 优先级

1. **高优先级**
   - 基础聊天界面
   - 实时预览功能
   - 流式文本生成

2. **中优先级**
   - 图片生成集成
   - 对话历史管理
   - 编辑功能

3. **低优先级**
   - 多语言支持
   - 模板系统
   - 分享功能
