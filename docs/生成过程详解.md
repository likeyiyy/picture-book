# AI绘本生成器 - 生成过程详解

本文档详细解释了AI绘本生成器的工作原理和生成流程。

## 系统架构概述

AI绘本生成器采用前后端分离架构，使用以下技术栈：
- **前端**：Next.js 14 + React + TypeScript + Tailwind CSS + Framer Motion
- **后端**：Next.js API Routes
- **AI服务**：OpenRouter API (DeepSeek v3.2 模型)
- **通信方式**：Server-Sent Events (SSE) 实现实时流式响应

## 生成流程详解

### 1. 用户输入处理 (`HomeChat.tsx` → `ChatInterface.tsx`)

#### 初始阶段
```typescript
// 用户在首页输入故事想法
const handleStartChat = (message: string) => {
  setInitialMessage(message);
  setHasStartedChat(true);
};
```

#### 输入解析
- 用户消息通过 `parseUserInput` 函数进行智能解析
- 自动识别以下信息：
  - **年龄段**：识别"X岁"关键词，默认4-6岁
  - **主角**：识别"小猩猩"、"小兔子"、"小明"等预设角色
  - **场景**：根据角色推断场景（森林、学校等）
  - **创作意图**：判断是创建新故事还是修改现有故事

### 2. API请求建立 (`ChatInterface.tsx` → `/api/chat/stream`)

#### EventSource 连接
```typescript
// 创建 SSE 连接实现实时通信
const url = `/api/chat/stream?message=${encodeURIComponent(messageText.trim())}`;
const es = new EventSource(url);
```

#### 请求参数
- **message**：用户输入的故事描述
- **自动识别的参数**：
  - `ageGroup`：年龄段（2-4、4-6、6-8）
  - `pageCount`：页面数量（默认5页）
  - `artStyle`：艺术风格（默认卡通风格）
  - `mainCharacter`：主角名称
  - `setting`：故事场景

### 3. 故事生成 (`/api/chat/stream` → `generateStoryPrompt`)

#### Prompt工程
系统使用精心设计的Prompt模板：

```typescript
const prompt = `请生成一个适合${ageGroup}岁儿童的绘本故事，主题是"${theme}"。

要求：
1. 主角：${mainCharacter}
2. 故事背景：${setting}
3. 页数：${pageCount}页
4. 寓意：${moral}
5. 语言：简单易懂，符合儿童认知水平
6. 结构：每页一段文字，不超过50字`;
```

#### AI模型调用
- 使用 **DeepSeek v3.2** 模型
- 参数配置：
  - `temperature: 0.8` - 保持一定的创造性
  - `max_tokens: 2000` - 足够生成完整故事
- 系统角色设定：专业的儿童绘本作家

#### 返回格式
严格遵循JSON结构：
```json
{
  "title": "故事标题",
  "pages": [
    {
      "pageNumber": 1,
      "text": "第一页文字内容（不超过50字）",
      "imagePrompt": "插图生成提示词"
    }
  ]
}
```

### 4. 实时数据流处理 (SSE)

#### 流式响应结构
系统通过SSE推送不同类型的数据：

1. **message类型**：聊天消息
```json
{
  "type": "message",
  "content": "收到你的想法，让我为你创作一个精彩的绘本故事..."
}
```

2. **book_update类型**：绘本数据更新
```json
{
  "type": "book_update",
  "data": {
    "title": "故事标题",
    "currentPage": 1,
    "pages": [...],
    "generating": true/false
  }
}
```

3. **complete类型**：生成完成
```json
{
  "type": "complete"
}
```

4. **error类型**：错误信息
```json
{
  "type": "error",
  "message": "错误详情"
}
```

### 5. 前端状态更新 (`ChatInterface.tsx`)

#### 状态管理
```typescript
// 聊天消息状态
const [messages, setMessages] = useState<Message[]>([]);

// 绘本数据状态
const [bookData, setBookData] = useState<BookData>({});

// 加载状态
const [isLoading, setIsLoading] = useState(false);
```

#### 实时更新机制
- 使用 `useEffect` 监听 EventSource 消息
- 根据消息类型更新不同状态
- 自动滚动到最新消息
- 支持中断生成过程

### 6. 绘本预览渲染 (`BookPreview.tsx`)

#### 双栏布局设计
- **左侧（20%）**：聊天界面
  - 显示对话历史
  - 输入框和发送按钮
  - 实时加载状态

- **右侧（80%）**：绘本预览
  - 显示绘本封面
  - 分页展示故事内容
  - 插图占位区域
  - 翻页交互效果

### 7. 错误处理与降级方案

#### API调用失败处理
- 检查API Key配置
- 提供Mock数据作为降级方案
- 友好的错误提示

#### Mock数据生成
内置多个预设故事的Mock数据：
- 小猩猩找妈妈
- 分享的快乐
- 神奇的冒险

### 8. 用户体验优化

#### 实时反馈
- "正在思考和创作..."提示
- 逐页生成动画效果
- 生成进度显示
- 支持随时停止生成

#### 交互细节
- Enter发送，Shift+Enter换行
- 避免重复发送相同消息
- 自动聚焦输入框
- 响应式设计适配不同屏幕
