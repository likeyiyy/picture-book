# 聊天式绘本生成器 - 使用指南

## 界面介绍

新的聊天界面采用左右分屏设计：

- **左侧（50%）**：聊天对话区
- **右侧（50%）**：绘本实时预览区

## 使用流程

### 1. 开始创作

在聊天框中输入你的故事想法，例如：
- "一个小猩猩醒来，在森林里找妈妈要抱抱的故事"
- "关于友谊的童话故事，适合3岁孩子"
- "小明和小红在月球冒险的故事"

### 2. 智能解析

系统会自动解析你的输入：
- 识别主角（如：小猩猩）
- 推断场景（如：森林）
- 判断年龄段（如有提到）
- 设定默认参数（页数、画风等）

### 3. 实时生成

生成过程中你会看到：
- 聊天区显示生成进度
- 预览区实时更新内容
- 逐页展示故事和插画描述

### 4. 完成后的交互

绘本生成完成后，你可以：
- 在预览区翻页查看
- 继续对话修改内容
- 开始创作新的绘本

## 交互特性

### 实时反馈
- ✅ 流式文本生成
- ✅ 逐页显示进度
- ✅ 动态更新预览
- ✅ 可中断生成

### 对话管理
- 保留完整对话历史
- 支持多轮交互
- 自然语言修正

### 预览功能
- 翻页查看完整绘本
- 显示插画描述
- 页码导航
- 生成状态指示

## 技术亮点

1. **Server-Sent Events (SSE)**
   - 实现服务器到客户端的实时推送
   - 无需轮询，降低服务器压力

2. **智能解析**
   - 自然语言处理
   - 自动提取关键信息
   - 智能默认值设置

3. **流式渲染**
   - React Suspense
   - Framer Motion 动画
   - 优化的用户体验

## 快捷键

- `Enter` - 发送消息
- `Shift + Enter` - 换行
- `Esc` - 停止生成（如果有停止按钮）

## 最佳实践

1. **清晰描述**
   - 简单明了地表达故事主题
   - 可以包含角色、场景、情感等要素

2. **自然对话**
   - 不需要完整的句子
   - 可以像聊天一样表达

3. **迭代优化**
   - 生成后可以通过对话修改
   - 具体指出需要调整的部分

```

```
